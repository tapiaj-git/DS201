# DS201

Student Learning Outcomes
Students will be able to:
a) Extract, transform, and load datasets:
o Use SQL to create tables and insert, modify, retrieve, and delete data.
o Use a database composed of at least 2 tables.
b) Perform Exploratory Data Analysis using multiple techniques and tools:
o Perform summary statistics suitable to specific data types
o Create effective visualizations
o Understand the advantages and disadvantages of different visualization approaches.
c) Apply machine learning methods and assess the quality of their output:
o Train and test machine learning models
o Develop scripts to build program pipelines.
d) Work effectively in teams on data science projects.
o Apply the Data Science processes and principles to solve a problem
o Effectively communicate results.
o Discuss the ethical and privacy considerations in the decision to collect, store, use, and/or
display a piece (or sub-pieces) of data.
